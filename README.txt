# Birthday Surprise — No Expiry Version

This version works immediately and has NO countdown or date-based lock.

Birthday is displayed as 1 October, but the website can be opened any time.

## Open without Live Server
Double-click `index.html`.
The browser address will look like:
file:///C:/.../birthday-surprise-no-expiry/index.html

## Temporary images
The page currently uses public Unsplash image URLs so you can see the design immediately.
Later, replace the image URLs in `index.html` with your own photos.

## Customize
Search `My Love`, `Happy Birthday`, and the letter text in `index.html` and replace them with your real names/message.

No installation or server is required.
